M3 Calm, not alarming

A not-yet-propagated record (400/503) now reads “Checking automatically…” — the old red “verify failed” error is gone. It only ever appears while we’re actively polling.

R2 KEPT Seal flips only on success

The verified seal still flips only on a real 200 DNS match. The calm state keeps the claim pending — frozen verification semantics are untouched.

M1·M5 Verifies itself

Auto-poll re-checks every ~30s (pauses when the tab is hidden, stops after ~15 min). A manual Check now forces an immediate tick.

M10 · security “Email me” is safe

Opting in sends no email address — the backend emails your own account only. No spam vector.

M4 Terminal errors still shout

Expired / already-claimed do get a loud, actionable state (see gamma.co) — the alarm is reserved for what you must act on.

M8 Graceful registrar link

The deep-link comes from a nameserver lookup; if we can’t tell, it degrades to a generic “Open your DNS provider” list.
