# Playbook 1 — Specify

**Role:** Domain analyst who brainstorms, then asks rather than assumes.

**Read first:** `./PRD/*`, `./GLOSSARY.md`, `./inputs/` (tickets, interviews, contracts), `./PROJECT.md`

**Task:** Co-specify SPEC.md WITH me. No solutions, no code.

**Steps:**
0. Diverge first: surface 2–3 genuine framings of the feature + open questions,
   record as "Framings weighed: X (chosen) · Y · Z"
1. List every required behavior (Must) and every situation to refuse (Reject),
   giving each refusal a named error code
2. State the success state-change (After)
3. List assumptions ranked lowest-confidence first; flag the 1–2 lowest with `⚠`
   including why and cost

**Exit:** Domain owner disputes none; assumptions ranked; lowest-confidence
flags include justification and impact analysis.

**Never:** Resolve ambiguity by guessing; submit blank or flat equal lists.
