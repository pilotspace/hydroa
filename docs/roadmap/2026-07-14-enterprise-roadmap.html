Hydroa as an enterprise LLM provider: gap analysis vs Claude cloud & the ship roadmap

Anthropic's cloud business decomposed against what Hydroa ships today, what changed in the last 60 days, and a three-release roadmap — Agent Gateway → Cost Optimizer → Platform Complete — with UI/UX as a first-class track. Approved by Tin 2026-07-14 (1.0.0 reserved for SOC 2 attestation).

2026-07-14Basis: Hydroa 0.8.0 (FEATURES.md · CHANGELOG · PRs #60–71) 2 fresh research sweeps, primary-sourced

0The thesis

Hydroa's 0.8.0 already covers most of what Anthropic's enterprise wrapper monetizes — seats, SCIM/SAML, domain capture, ZDR, compliance export, audit, spend controls (and Hydroa's budgets are API-managed where Anthropic's are still Console-UI-only). The two places Anthropic is running away with the market are agent-era surfaces (Managed Agents, MCP connectors, its own new first-party gateway) and distribution economics (cache/batch/priority/regional price mechanics).

The re-verified whitespace is unchanged and still uncontested: no vendor among 14 scanned ships downstream-tenant billing (reseller invoices, prepaid credits, seats for your customers' customers) — Hydroa shipped exactly that in 0.8.0. The play now is to defend that lead while closing the agent-gateway gap before it commoditizes, and to convert the EU residency work into revenue while the EU AI Act Art. 101 enforcement date (Aug 2, 2026) makes every EU platform team's audit posture urgent.

What changed since the July-12 analysis

Anthropic shipped its own gateway. "Claude apps gateway" (launched Jun 29–Jul 2) fronts Claude Code across Bedrock/Vertex/Foundry with SSO, per-user cost tracking, spend caps, and failover — and Anthropic is publishing the gateway protocol for third parties. It is single-org and Claude-only. It validates the category, competes with the narrow "front Claude Code" slice of M3, and hands Hydroa a spec to implement: be the multi-tenant, multi-provider, billing-grade implementation of the protocol Anthropic just legitimized.

3Market signals that shaped the sequencing

  • EU AI Act: Art. 101 GPAI penalty powers apply Aug 2, 2026 (3% global turnover / €15M — don't quote the €35M/7% Art. 99 figure; competitors get this wrong). Obligations sit on model providers, so the honest sellable is deployer-side: EU-pinned routing + Art. 12-mapped record-keeping + audit export. Hydroa has all the machinery; it needs packaging, not code.
  • MCP is enterprise-real: ~97M SDK downloads/mo, 28% of the Fortune 500 deployed, CISA-KEV'd gateway CVEs — and governance demand (allow-lists, agent rate limits, session tracing) is outpacing supply.
  • Agent identity is a budget line now (Okta for AI Agents GA Apr 30; Auth0 May 21): 88% of orgs report agent security incidents, 22% treat agents as identity-bearing principals.
  • FinOps: 98% of orgs now manage AI spend. The maturity ladder is showback → chargeback → gateway-enforced pre-spend blocking; Hydroa's fail-closed credit gate is already top-rung — market it that way.
  • Pricing norms: unlimited seats is the anti-incumbent wedge (only TrueFoundry seat-gates); platform fees ≈ 5% (OpenRouter 5.5%, Requesty 5%, Vercel/CF 0%); the only hard enterprise-contract data is Kong's Vendr median $63k/yr (range $30k–$249k).
  • Consolidation is fast: Portkey→Palo Alto, Helicone→Mintlify (maintenance mode), Promptfoo→OpenAI, 4 new gateway entrants in 5 months. The billing whitespace is a lead, not a moat.
  • OTel GenAI semconv is not stable (zero tagged releases). Say "OTel-aligned, tracking the spec," never "fully compliant."

4The roadmap — three releases to 1.0

Sequenced by revenue timing: the AI-Act window closes Aug 2; the MCP race is being run now; cost optimization compounds after the agent traffic exists. Every milestone runs the ADD loop (spec bundle → frozen contract → red/green build → adversarial verify; security tasks get dual independent verifies per the M2 lesson).

R1a · quick strike

eu-ai-act-readiness

~1 week, parallel to M3 wave 1 — pegged to Aug 2

Convert the shipped residency + compliance stack into a sellable "EU AI Act readiness" package before enforcement day makes every EU buyer ask for it.

  1. art12-record-keeping-preset — a one-click compliance-export bundle mapped to Art. 12 record-keeping (logs + audit + usage lineage), with a generated cover report. Assembly over existing export APIs.
  2. ai-act-marketing-page UI/UX — marketing page + docs: residency (fail-closed, refuse-not-reroute) + ZDR + audit story; correct Art. 101 figures; Fable-5 export-suspension vendor-risk narrative for multi-provider failover.
  3. compliance-report-center UI/UX — console surface: generate/download the Art. 12 bundle, scheduled monthly generation.

Exit: an EU tenant can produce a dated record-keeping bundle in one action; the marketing page ships before Aug 2.

R1b · M3 (queued, expanded)

agent-gateway-v1

~2–3 weeks → release 0.9.0

Make Hydroa the multi-tenant, multi-provider, billing-grade agent gateway — the full five-primitive governance set no competitor holds (session governance · MCP allow/deny lists · tracing · agent rate limits · tool metering).

  1. anthropic-messages-ingress — native /v1/messages (+ token counting), SSE translation, billing parity across the shared recorder. Already Tin-approved; unlocks Claude Code / Agent SDK traffic.
  2. claude-gateway-protocol-compat — new since the research: implement Anthropic's published gateway protocol so Claude Code fronts Hydroa first-class; differentiate on multi-tenant + non-Claude failover, which their gateway won't do.
  3. mcp-connector-passthrough security hard-stop ×2 — MCP egress proxy with tenant-admin allow/deny lists, fail-closed on unlisted servers; session tracing into the Logs Explorer.
  4. tool-call-metering — per-tool-call pricing units ($/1k-query via the existing pricing_unit dispatcher) → usage_records → invoice lines. First-mover: no metering standard exists yet.
  5. agent-identity-governance security hard-stop ×2 — agent-as-principal on device-OAuth: named agent identities, per-agent budgets/rate limits, universal kill switch (instant revoke of all sessions/tokens).
  6. agents-console UI/UX · UDD loop — Agents page: directory (identity, owner, last-seen, spend), session explorer with traces, MCP allow-list management, kill switch with typed-confirm gate (ZDR idiom).

Exit: a tenant fronts Claude Code through Hydroa, governs which MCP servers its agents may touch, sees per-agent spend on the invoice, and can kill an agent in one click. 0.9.0 "Agent gateway".

R2 · M4 (cluster-3 reframed)

cost-optimizer

~2 weeks → release 0.10.0

Monetize the price mechanics Anthropic invented: capture cache/batch/channel deltas as tenant savings and operator margin, and finish FinOps parity.

  1. per-alias-routing-override — routing strategy per alias (today one global setting) + cost-aware "cheapest capable" strategy.
  2. batch-brokering — auto-classify latency-insensitive traffic into the −50% batch window (opt-in per key), delayed-billing reconciliation via the existing signed-delta path.
  3. tenant-vector-cache-toggle — per-tenant vector-cache opt-in + embedding-model choice (today a global env flag).
  4. spend-anomaly-alerts — threshold alerts (75/90% parity with Anthropic) + z-score spike detection, per-tenant webhook sinks (today one global sink).
  5. finops-dashboard UI/UX · UDD loop — savings view ($ saved by cache/batch/routing vs list price), anomaly feed, spend forecast; OTel-aligned analytics export (Datadog et al.).

Exit: the dashboard shows a real "you saved $X this month" figure computed from usage_records, and an anomalous key pages the tenant's own webhook. 0.10.0 "Cost optimizer".

R3 · M5 + M6

prompt-evals-lite & commercial hardening

~3 weeks → release 0.11.0

The last gateway-category differentiators plus the commercial finish line.

  1. prompt-registry — versioned prompts callable as prompt:name@ver (reuses the preset colon-prefix seam), git-like immutable versions + environment tags.
  2. shadow-ab-routing — traffic mirroring to a silent model + weighted canary with auto-revert; results into eval analytics.
  3. golden-set-evals — tenant-defined eval sets run against gateway traffic samples; guardrail-policy playground (test before rollout).
  4. developer-portal UI/UX · UDD loop — onboarding wizard (tenant → BYOK → first call in <5 min), API docs surface, model deprecation lifecycle notices.
  5. ga-commercial-hardening — SOC 2 evidence automation groundwork (independent auditor — the LiteLLM cert scandal made auditor identity a buying criterion), pricing page final, SPEC-delta triage sweep (todo #38), perf catalog remainder.

Exit: a stranger can self-serve onboard and pay; prompts/evals close the last differentiator gap. 0.11.0 "Platform complete" — the 1.0.0 label is reserved for the SOC 2 attestation milestone (Tin's call, 2026-07-14).

7Risks & counters

  • Anthropic's gateway grows multi-provider. Unlikely soon (ToS forbids routing Claude surfaces to non-Claude models; single-org design) — but implement their protocol early so Hydroa rides their docs, not against them.
  • Whitespace closes. Kong Metering & Billing is one positioning pivot away. Counter: ship agent-era billing (tool metering on invoices, 0.9.0) so the moat compounds; re-verify the vendor scan at every release cut.
  • MCP spec churn (RC locked May 21, six auth SEPs). Build the passthrough against the RC; keep the allow-list model transport-agnostic.
  • Foundry-EU lands. "Coming 2026," no date. When it does, Hydroa's residency story shifts from "only path to EU Claude" to "one policy across every provider's EU" — still sellable, weaker headline. Another reason to sell hard now.
  • Cert gap: ZDR/HIPAA-shaped features exist but Hydroa-the-operator has no SOC 2. That's the real Enterprise-sales blocker beyond ~$30k deals; groundwork starts in R3, audit is a business decision outside the codebase.
