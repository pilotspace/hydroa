Token-bucket, in short

A bucket refills with tokens at a steady rate up to a fixed capacity; each request spends one, so bursts are allowed up to the cap while the long-run average is bounded by the refill rate.

local function refill(b, now)
  b.tokens = math.min(b.cap, b.tokens + b.rate * (now - b.last))
  b.last = now; return b.tokens
end
